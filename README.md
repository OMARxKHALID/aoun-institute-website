# aoun-institute-website

Marketing site and learner pages for Aoun Institute. Next.js 16 (App Router), React 19, Tailwind CSS v4, GSAP.

## Commands

```bash
bun install
bun dev
bun run build
```

## Structure

- `app/` routes
- `components/sections/` page sections
- `components/ui/` reusable UI blocks
- `components/motion/` animation wrappers
- `lib/data.js` all site content (courses, jobs, webinars, contact details)
